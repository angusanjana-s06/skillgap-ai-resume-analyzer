# SkillGap AI – Resume Skill Analyzer

SkillGap AI is a Python and Streamlit-based resume analyzer that identifies skills from a resume, compares them with the requirements of a selected job role, calculates a skill-match score, and highlights missing skills to help users understand and improve their career readiness.

## Features

- Upload a resume in TXT format
- Extract technical skills from the resume
- Select a target job role
- Compare existing skills with role requirements
- Identify missing skills
- Calculate skill-match percentage
- Display progress using a Streamlit progress bar
- Provide basic feedback based on the score

## Available Job Roles

- Python Developer
- Data Analyst
- Web Developer

## Technologies Used

- Python
- Streamlit
- Git
- GitHub

## How It Works

1. Enter your name.
2. Upload your resume.
3. SkillGap AI scans the resume for known skills.
4. Select your target job role.
5. The application compares your skills with the required skills.
6. Missing skills are displayed.
7. A skill-match score is calculated.

## Example

For a Python Developer role, the required skills may include:

- Python
- Git
- Streamlit
- SQL

If the resume contains Python, SQL, and Streamlit but does not contain Git, the application identifies Git as a missing skill and calculates the corresponding skill-match score.
